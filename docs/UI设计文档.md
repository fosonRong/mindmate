## 1. 设计概述

### 1.1 设计理念

**"像坐在你旁边的伙伴，而不是盯着你的仪表盘。"**

智伴的界面应当是：安静、温暖、低负担。它替你管理记录与提醒，所以界面不该制造焦虑（无红点轰炸、无夸张动效）；它是 AI 伴侣，所以与被 AI 生成的感受（流式文字、洞察卡片）应当有"活着的温度"。

### 1.2 三个设计原则

| 原则 | 落地 |
| --- | --- |
| **记录零摩擦** | 速记输入框在任何页面常驻可见、光标就位；全局热键 3 秒完成一次记录；任何"录入"路径不超过 1 次点击 + 1 次回车 |
| **克制不打扰** | 提醒可全部关闭；达标即静默；徽标、动效、弹窗只出现在真正重要处；界面信息密度向"留白"倾斜 |
| **AI 有温度** | 流式打字机渲染一切 AI 输出；洞察用一句话卡片而非数据表格；未经配置模型时给出友好的引导而非报错 |

### 1.3 情绪板

- 主色调：**智伴紫**（AI 感、陪伴感）
- 辅以：暖中性底色（纸感）、**火光橙**（激励/连续记录）、语义色（进度分级）
- 意象：柔和的渐变、圆角卡片、气泡式的记录形态，避免直角硬朗的企业工具感

## 2. 设计令牌（Design Tokens）

### 2.1 色彩

**主题三态（设置）**：`跟随系统`（默认）｜`浅色`｜`深色`

- 实现：CSS 变量顶层覆盖（见 9.1 主题引擎），切换即时生效、无刷新、无闪烁（预注入），绑定 `prefers-color-scheme` 随系统实时联动；桌面端与浏览器端行为一致。

### 2.2 字体

| 项 | 值 |
| --- | --- |
| 中文字体 | `-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` |
| 数字/时间字体 | `"JetBrains Mono", ui-monospace, monospace`（等宽，tabular-nums） |
| 字号阶梯 | 12 / 13 / 14 / 16 / 20 / 24 / 32 |
| 行高 | 正文 1.6，标题 1.3 |
| 字重 | 常规 400，强调 500，大标题 600 |
| 主题联动 | 跟随系统模式下，字号与行高保持不变，仅颜色/阴影/渐变切换（避免系统主题切换引发布局抖动） |

应用：页面标题 24/600；卡片标题 16/600；正文 14/400（行高 22px）；辅助 12/400；时间戳 12/等宽/弱色。

### 2.3 间距 / 圆角 / 阴影

- **间距**：4px 基数 → 4 / 8 / 12 / 16 / 24 / 32 / 48。
- **圆角**：卡片 16 · 控件（输入框/按钮）10 · 标签/气泡 8 · 大弹窗 20 · 浮窗 16。
- **阴影**：
  - 卡片：`0 1px 2px rgba(15,18,30,.05)`；
  - 悬浮/下拉：`0 8px 24px rgba(15,18,30,.12)`；
  - 速记浮窗/Toast：`0 16px 48px rgba(15,18,30,.18)`。
- **描边**：默认 1px `--border`。

### 2.4 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| hover / active | 120ms | ease-out |
| 折叠 / 展开 / 抽屉 | 200ms | ease-out |
| 页面切换 / 弹窗 | 300ms | `cubic-bezier(.22,1,.36,1)` |
| 庆祝类（达标闪烁） | 500ms | 仅此一处用呼吸动画 |
| AI 流式打字机 | 16ms/帧 | — |

- 全部动效遵循 `prefers-reduced-motion: reduce` 时降级为无动画。

### 2.5 主题引擎（三态切换）

**设置项**：`跟随系统`（默认）｜`浅色`｜`深色`。保存到 `settings` 表，浏览器端同步生效。

| 环节 | 实现 |
| --- | --- |
| 生效机制 | 顶层 `data-theme="light|dark"` 属性切换 CSS 变量集；页面无刷新、无闪烁 |
| 跟随系统 | 启动时读 `matchMedia('(prefers-color-scheme: dark)')`；监听 `change` 实时联动（系统切换 → 界面即时跟随） |
| 预注入 | 前端入口脚本在渲染前注入 `data-theme`（读取 localStorage 快照），避免首帧闪白/闪暗 |
| 桌面端信标 | 桌面端监听系统主题变化（`tauri-plugin-os` 或 WebView 原生 matchMedia——WebView 已自动响应 `prefers-color-scheme`，无需额外插件），与浏览器端同一套逻辑 |
| 驱动 | 长窗口：主题选择持久化到 `settings.theme`；短窗口：首屏预注入从 localStorage 快照读取（与 `settings.theme` 镜像同步） |

**深色主题对照检查清单**（视觉验收并入第 9 章）：
- 卡片层级用描边区分，阴影仅浮层；
- 语义色（成功/警告/危险/信息）保持浅色同值，不因深色变暗而失辨识；
- 阴影透明度调高（黑色底上层级感弱），描边统一 `--border`；
- 文本选中、滚动条、占位符、禁用态均有对应深色令牌；
- 深色下所有截图/插画（渐变紫橙）保持原色，透明度 40% 底不变。

### 3.1 应用骨架

**桌面 / 宽屏（≥1280px）**

```
┌────┬────────────────────────────────────────────────┐

│ 航 │ [页面标题 20/600] [日期 12/弱]      [＋速记] [⚙] │
│ 64 │────────────────────────────────────────────────│
│ px │                                                │
│ 图 │                主内容区（12 栅格）              │
│ 标 │                                                │
│ 列 │                                                │
│    │                                                │

│ 底部状态条 24px: [● 同步中] [本地模式 · 17801]  [🔥5] │
```

- 左导航 64px：图标 + tooltip，五项：今日 / 周 / 月 / 待办 / 智伴（设置放顶栏齿轮）。

- 左导航消失 → **底部 TabBar 56px**（今日 / 周 / 月 / 待办 / 智伴），设置入口在顶部；
- 页面标题 + 日期简化；速记框吸顶常驻。

## 4. 通用组件规范

### 4.1 进度条 ProgressBar

- 结构：轨道 4px 高圆角 + 填充条；右侧文案 `已录 3/4 条`（12px 弱色）；
- 分级配色：`<30%` 灰 → `30–70%` 黄 → `>70%` 绿；超额满格 + 橙色 `已超额 n 条`；
- 变体：**环形**（56px）用于周视图每日待办完成率；**双条并排**（记录 + 待办）用于周期卡片，间距 16px，各自带 12px 标题。

### 4.2 速记输入框 QuickEntry

```
┌──────────────────────────────────────────────┐
│ 快速记录此刻的工作 / 生活…            [Enter↩] │
│   [工作] [生活] [健康] [学习]  [＋自定义标签]   │
└──────────────────────────────────────────────┘
```

- 尺寸：高 44px，圆角 10，底色 `--bg-hover`；聚焦时描边变 `--primary` 1.5px + 阴影 `0 0 0 3px primary-weak`；标签行仅在聚焦/输入时淡入；
- 提交：回车发送（`Ctrl+Enter` 换行），提交后内容清空、光标回位、播放 300ms 轻微"落位"动效并浮现 Toast `已记录 10:15`。

### 4.3 节点卡片 NodeItem（时间线）

```
  ┆
  10:15 ──●── [工作] 完成 XX 模块开发，联调通过
  ┆        │
  ┆        └── hover 浮出: [编辑] [删除] [关联待办]
```

- 时间轴：左侧竖线 + 圆点（12px，`--primary` 实心 = 今日节点；空心 = 补录 + 「补录」角标）；
- 时刻：12px 等宽 `--text-weak`，宽度固定 5 字符对齐；
- 内容：14px `--text-strong`，可多行；
- 标签：8px 圆角 Chip（分类色）；
- hover：整卡浮起（阴影 +1 级），操作按钮淡入；
- 编辑态：行内变为文本域 + [保存][取消]。

### 4.4 待办项 TodoItem

```
☑︎ 晨会同步需求                工作  09:00
☐ 修复登录 bug          ●高 ●⚠️逾期   今天
```

- 复选框：自定义 20px，完成 = `--success` 实心对勾；标题完成态 = `--text-disable` + 删除线；
- 优先级：不显眼的小圆点（高=红 / 中=橙 / 低=灰）；
- 逾期：标题后 `⚠️` 红色徽标 + 截止时间红色；
- 拖拽：左缘 12px 拖拽把手（hover 显示），拖到日历某天=改期，列表内拖=排序；
- hover 浮出：编辑 / 完成 / 删除 / 智伴建议（逾期或未完成时）。

### 4.5 周期卡片 ProgressCard（今日/周/月共用）

```
┌───────────────────────────────┐
│ 今日   🔥连续5天               │ ← 标题左，激励徽标右
│ 记录进度  ▓▓▓▓▓▓░░░ 已录3/4   │
│ 待办完成  ▓▓▓▓▓▓░░░ 3/5       │
└───────────────────────────────┘
```

- 卡片圆角 16、白底/深色卡片底；两进度条 8px 间距；点击卡片头部切换展开/收起内容区。

### 4.6 日历 Calendar

- 月视图：7 列网格，格高自适应（最小 72px）；今天 = 数字描边 `--primary`；选中 = 紫底圆角格；周末与邻近月日期弱化 40%；
- 格内元素（自左向右）：节点数徽标 `●n`（紫，有内容时）、待办圆点（蓝，≤3 个）、摘要一行（超长省略，hover 全文）；
- 周视图：横向 7 张卡片（复用周视图页设计），头部可切回月；
- 锁定：未来日期可预录（允许），不可选中仅展示汇总。

### 4.7 报告预览 ReportViewer

- 版式：白底 16 圆角卡，内距 24px；Markdown 渲染（DOMPurify 清洗）+ 14px 正文；
- **生成中**：标题下方闪烁光标块 `▍`（primary 色）；顶部进度条 8px 不定态动画；右上 [停止生成]；
- 生成后工具条（悬浮于卡片右上）：[复制 MD] [导出] [编辑] [归档]（归档后历史中可查）；
- **降级模式**（无 Key）：卡片顶部黄色信息条 `⚙ 当前为本地模板拼装，配置 AI 模型可获得更优质报告 →`，内容仍完整可复制。

### 4.8 聊天气泡（智伴问答）

- 用户：右对齐，`--primary` 底白字，圆角 12/4；
- 智伴：左对齐卡片，白底 + 描边，圆角 12/4；生成中带闪烁光标；
- 数据引用：回答末尾以 12px 弱色小字列出 `数据来源：09-10 · 联调接口 · 09-11 晚报`（可点击跳转）；
- 输入框：44px，Enter 发送 / Shift+Enter 换行；发送中禁用并显示三点点阵。

### 4.9 洞察卡片 InsightCard（复盘页）

```
┌─ ✦ ──────────────────────────┐
│  周三的待办逾期率最高（43%）    │ ← 一句话，14/500
│  本周逾期 6 件中 3 件集中在周三  │ ← 支持数据 12/weak
└───────────────────────────────┘
```

- 左侧 `✦` 徽标（primary-weak 底）；卡片 hover 微浮；瀑布流两列布局（移动端单列）。

### 4.10 空状态 EmptyState

- 结构：居中插画（渐变圆 + 简单线条人物/咖啡杯，primary 系渐变 `#6C5CE7→#FF9F43` 40% 透明度做底）+ 标题（16/600）+ 说明（13/weak）+ 主按钮；
- 各页文案示例：
  - 今日无记录：`今天还没有记录，记下第一笔吧` [开始记录]
  - 无待办：`此刻一身轻 ✨` [＋ 添加待办]
  - 无报告：`报告从这里开始` [生成今日日报]
  - 未配置 AI：`让智伴帮你整理` [配置 AI 模型]（两步引导卡片）

### 4.11 弹窗 / Toast / 确认

- Dialog：宽 400–560px，圆角 20，遮罩 `rgba(15,18,30,.4)` + 200ms 淡入；标题 16/600 + 内容 14 + 底部按钮（次→主）；
- Confirm（危险操作）：主按钮 `--danger`；
- Toast：右上角滑入 300ms，3 秒自动消失，最多堆叠 4 条；等级色左缘 3px 竖条；
- 页面内横幅（浏览器提醒兜底）：顶部滑入，圆角 12，左图标 + 文案 + [立即速记][关闭]。

### 4.12 速记浮窗 QuickFloat（桌面）

```
┌────────────────────────────┐  ≤ 360×200，置顶无边框
│ ⏺ 09-12 14:32    今日 3/4  │  标题行 12px
│ 记录此刻…                   │  输入区 44px
│ [工作][生活][健康][学习]     │  标签行
│              [Esc 取消][✔]  │  按钮行
└────────────────────────────┘
```

- 边框 1px 描边 + 大阴影；圆角 16；Enter 保存并 0.5s 绿勾反馈后关闭；Esc/点击窗外/再按热键关闭；位置：屏幕居中偏上，记住上次位置。

### 5.6 设置 Settings（`/settings` 或抽屉）

- 左侧分组菜单（240px）：提醒 / 每日目标与热键 / AI 模型 / 外观 / 数据与部署 / 关于；
- **AI 模型页**：
  - 顶部两张预设大卡（选中态 = primary 描边 2px + 对勾）：`智谱 GLM`（免费徽标）`DeepSeek`（性价比徽标）；
  - 下方表单：Base URL / API Key（密码框 + [显示]）/ 模型名（带下拉建议）/ 温度滑条 / max_tokens；
  - `[测试连接]` 结果：成功绿勾 + 延迟 + 模型回显；失败红条 + 可读原因；
  - 脱敏规则折叠项：默认规则开关 + 自定义词组编辑（每行一条，`原文→替换`）；
- **提醒页**：频率（预设卡片单选：每小时/2小时/4小时/自定义分钟/Cron 文本）+ 生效时段（双滑条 08:00–21:00）+ 各开关组 + 勿扰规则列表（新增：一次性/重复，时段选择）；每个规则旁 `说明` 图标弹 tooltip 说明行为；
- 表单风格统一：label 上置 13px，控件 40px 高；错误：红描边 + 下方 12px 红字。

## 6. 响应式与断点

| 断点 | 布局行为 |
| --- | --- |
| ≥1280 桌面 | 左导航 64px + 顶栏 56px；今日页 8/4 栅格；待办中心并排 |
| 768–1279 平板/小窗 | 左导航收窄为图标（无文字）；今日页单列；待办 = 日历 + 抽屉列表 |
| <768 移动浏览器 | 底部 TabBar 56px；速记框吸顶；周/月视图单列滚动；待办 = 分段控件（列表/日历）；对话框全屏化（底部滑入） |

- 触屏目标：所有可点控件 ≥ 40×40px；
- 桌面能力注入：`isDesktop` 为真时显示热键提示（如速记框右侧 `Alt+Z` 小字）与浮窗入口，浏览器端隐藏。

## 7. 无障碍

| 项 | 要求 |
| --- | --- |
| 对比度 | 正文与背景 ≥ 4.5:1；弱色文字仅限装饰性内容 |
| 焦点 | 可见焦点环 2px `--primary`；键盘 Tab 序：导航 → 内容 → 工具条 |
| 语义 | 列表用 `<ul>/<li>`；时间线用 `<time>`；日历用表格语义 + `aria-label`（"09-14 周一，3 条记录，2 件待办"） |
| 表单 | 错误信息 `aria-describedby` 关联；输入框均带 label |
| 动效 | `prefers-reduced-motion` 全部降级 |
| 通知 | 通知亦可从"提醒记录"页查看历史，不依赖实时弹窗 |

## 8. 全局状态模板（复用在所有页面）

| 状态 | 呈现 |
| --- | --- |

| AI 降级 | 黄色信息条（4.7），不阻断操作 |
| 首次使用 | 三步引导（部署模式 → 每日目标 → AI 可跳过），可随时跳过，设置页可重开 |
