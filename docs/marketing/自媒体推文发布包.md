## 产品核心卖点（文案素材库）

- **本地优先，隐私放心**：数据存在自己电脑里（SQLite），不上传任何服务器；AI Key 只存本机系统钥匙串；AI 请求直连模型厂商，不经过第三方。
- **AI 可选，不用也能转**：不配 Key 全功能可用（本地规则兜底）；配了 Key 解锁全部 AI 能力。
- **模型随便换**：智谱 GLM（glm-4-flash 免费）、DeepSeek、OpenAI、通义千问、Kimi，还支持 Ollama 本地模型——断网也能跑 AI。
- **为中文职场而生**：日程自带农历、节假日调休（休/班）；一句话速记自动拆待办、认时间（"明天下午3点开会"直接变日程）。
- **有迹可循**：随手记 → 智能归类 → 一键排期 → 逾期顺延 → AI 日报/周报/月报 → 下周计划，完整闭环。
- **免费**：目前完全免费，无订阅无广告。
- **轻量跨平台**：Windows / macOS，安装包不到 6MB，本地秒开。

## 三、微信公众号版（长文，直接可排）

**标题**：我把 AI 装进本地待办里：智伴 Mindmate，打工人的第二大脑
**摘要**：数据不出本机，AI 反而更能打——一款为中文职场做的本地优先 AI 工作伴侣。

**正文：**

### 为什么又写一款效率工具？

市面上的待办/笔记工具很多，但对中文职场总差一口气：不认农历和调休、拆不了"明天下午3点开会"这种自然语言、想出个周报还得手动整理。更别提数据全在别人云上。

**智伴 Mindmate** 的思路是：**数据留在本地，AI 按需接入**。

### 它能做什么？

**1. 记录快到无感**
全局速记浮窗（Alt+Z）随时唤起；一句话丢进去，智能速记自动拆成待办、识别日期时间、打好标签。截图直接粘贴，文字自动识别（OCR）。

**2. 日程懂中国日历**
周视图/月视图自带农历、节假日与调休标记（休/班）；格子随屏幕自适应排布，一眼看清一周节奏。

**3. 待办从收集到排期一条龙**
灵感没想清楚？先扔收集箱。想清楚了？AI 智能归类（待办/资料/笔记）。排期不想动脑？一键智能排期：按优先级 × 截止 × 每日容量，把逾期和未完成自动铺进未来工作日，周末自动跳过，预览确认才写库，应用了还能一键撤销。

**4. AI 报告，汇报不熬夜**
日报/周报/月报基于你自己录的内容生成，只陈述事实不编造；周报证据链直接列出"本周完成了哪些待办"；报告模板还能**跟 AI 对话式生成**——说一句"面向领导，结论先行"，模板立刻重写。

**5. 隐私是底线，不是卖点话术**
数据存本机 SQLite，AI Key 存系统钥匙串，AI 请求直连厂商。不配 Key 全功能可用；配了 Key，智谱 GLM（glm-4-flash 免费）/ DeepSeek / OpenAI / 通义千问 / Kimi 任选，也支持 Ollama 纯本地模型。
