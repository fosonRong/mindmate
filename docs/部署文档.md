# 智伴 Mindmate — 部署文档

> 覆盖三种部署形态：**桌面端（默认）**、**局域网共享**、**服务器（Docker + HTTPS）**，
> 以及升级、备份、故障排查。所有形态共用同一个二进制与同一份数据模型。

---

## 1. 形态对照

| 形态 | 适用 | 提醒由谁驱动 | 访问方式 |
| --- | --- | --- | --- |
| 桌面端（本地模式） | 个人主力（推荐） | 桌面进程（托盘常驻） | 本机窗口 + 浏览器 `http://127.0.0.1:17801` |
| 局域网共享 | 家里/小团队多设备 | 桌面或服务器进程 | 同网段设备浏览器访问 `http://<主机IP>:17801` |
| 服务器（Docker） | 异地、多设备、7×24 | 服务端定时器（服务不关机即生效） | 浏览器访问域名，经反向代理启用 HTTPS |

---

## 2. 桌面端（Windows）

### 2.1 安装

1. 双击 `Mindmate_1.0.0_x64-setup.exe`（当前用户安装，无需管理员）
2. 首次启动会显示 3 步引导（使用方式 → 每日目标 → AI 模型，可跳过）
3. 托盘常驻：关闭窗口 = 隐藏到托盘，提醒继续生效

### 2.2 绿色版（免安装）

直接运行 `mindmate.exe`；数据目录可通过 `--data-dir` 指定，便于放在 U 盘等场景。

### 2.3 常用启动参数

| 参数 | 说明 |
| --- | --- |
| `--mode local` | 默认，仅监听 127.0.0.1 |
| `--mode lan` | 监听 0.0.0.0，需在设置中设置访问密码 |
| `--mode server --headless` | 无窗口纯后端（容器/服务器使用） |
| `--port 17801` | 指定端口（默认 17801，被占用时自动 +1 直至 17820） |
| `--data-dir D:\mindmate-data` | 指定数据目录 |
| `--lan` | 本地模式下额外开放局域网访问 |
| `--healthcheck` | 健康探针：请求本机 healthz，成功退出码 0 |

环境变量等价形式：`MINDMATE_MODE` `MINDMATE_PORT` `MINDMATE_DATA_DIR` `MINDMATE_LAN` `MINDMATE_LOG` `MINDMATE_WEB_DIR`。

## 3. 局域网共享

1. 桌面端启动时加 `--lan`（或设置页把部署模式改为局域网并重启）
2. 首次进入浏览器访问时会提示**设置访问密码**（Argon2id 哈希存储，至少 6 位）
3. 同网段设备浏览器访问 `http://<主机IP>:17801`，输入密码登录（JWT 有效期 30 天）
4. Windows 首次开放需允许防火墙入站（专用网络）

> 安全提示：局域网模式请仅在可信网络使用；如需公网访问，请走下一节的服务器形态并启用 HTTPS。

## 4. 服务器部署（Docker）

### 4.1 一键启动

```bash
# 1) 构建前端产物（容器内需要）
npm install --prefix apps/web && npm run --prefix apps/web build

# 2) 启动服务
docker compose up -d

# 3) 查看状态
docker compose ps && docker compose logs -f --tail=50
```

浏览器访问 `http://<服务器IP>:17801`，首次进入设置访问密码。

### 4.2 数据持久化

数据卷映射为宿主 `./data`：

```
data/
├── data.db          # SQLite 主库（WAL 模式，含 data.db-wal / data.db-shm）
├── .token           # 本地访问 token（0600）
├── .jwt             # JWT 签名密钥（0600）
└── logs/            # 按天滚动的运行日志
```

**备份**：直接拷贝整个 `data/` 目录（建议先停容器，或用设置页的「导出全部数据」）；**恢复**：停容器后覆盖 `data/` 再启动。

### 4.3 启用 HTTPS（推荐）

编辑 `Caddyfile.example` 把域名改成你的域名，然后：

```bash
# 1) 准备 Caddyfile
cp Caddyfile.example Caddyfile
# 2) 取消 docker-compose.yml 中 caddy 服务的注释
docker compose up -d
```

关键配置是 `flush_interval -1`——关闭代理缓冲，否则 SSE（报告流式输出）会攒够一批才到达浏览器。

### 4.4 不用 Docker：systemd 直接托管

```ini
# /etc/systemd/system/mindmate.service
[Unit]
Description=Mindmate
After=network.target

[Service]
Type=simple
User=mindmate
WorkingDirectory=/opt/mindmate
ExecStart=/opt/mindmate/mindmate --mode server --headless --data-dir /var/lib/mindmate --port 17801
Restart=always
RestartSec=3
Environment=MINDMATE_LOG=info

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now mindmate
sudo systemctl status mindmate
```

## 5. AI 模型配置

| 提供商 | Base URL | 推荐模型 | 说明 |
| --- | --- | --- | --- |
| 智谱 GLM（默认） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 免费额度，零成本跑通全部 AI 功能 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 长报告质量好 |
| OpenAI / 通义 / Kimi | 见设置页预设 | — | 任意 OpenAI 兼容接口 |
| Ollama（本地） | `http://localhost:11434/v1` | `llama3.2` | 完全离线，无需 Key |

- API Key 存**后端所在机器**的系统安全存储（桌面=本机钥匙串/凭据管理器；服务器=Docker 容器内密钥环），接口不回传明文。
- 服务器模式下建议 `-e` 挂载密钥环或改用 Ollama 本地模型。
- 未配置 Key 时，全部生成能力自动降级为本地模板，功能不空转。

## 6. 提醒渠道

| 渠道 | 配置位置 | 适用 |
| --- | --- | --- |
| 桌面系统通知 | 自动 | 桌面端 |
| 浏览器通知 / 页面横幅 | 设置 → 提醒 → 请求权限 | 浏览器端 |
| 企业微信机器人 | 设置 → 推送渠道 → Webhook | 服务器模式推荐 |
| 邮件（SMTP） | 设置 → 推送渠道 | 任何形态 |
| Telegram Bot | 设置 → 推送渠道 | 任何形态 |

每个渠道都有独立「测试」按钮：点一下即可确认凭据与网络是否可用。凭据分别存系统安全存储，与 AI Key 互不影响。

## 7. 升级

```bash
# 桌面端：直接覆盖安装新版本；数据在 %APPDATA%\Mindmate，不会丢失
# 服务器：
git pull && npm run --prefix apps/web build
docker compose build && docker compose up -d
```

数据目录与镜像分离，升级只替换程序；数据库结构变更由内置迁移自动应用（`PRAGMA user_version` 版本管理）。

前端资源采用内容哈希命名 + `index.html` 强制校验，升级后不会出现新旧资源混用。

## 8. 故障排查

| 现象 | 排查 |
| --- | --- |
| 浏览器打不开 | `curl http://127.0.0.1:17801/api/v1/healthz`；检查端口占用（自动顺延至 17820） |
| 报告不流式/卡住 | 反向代理未关闭缓冲 → 按 §4.3 设置 `flush_interval -1` |
| 提醒不触发 | 设置 → 提醒：确认总开关、生效时段、勿扰规则；已达每日目标会静默（设计如此） |
| 收不到邮件 | 用「测试」按钮看返回；企业邮箱/QQ 邮箱需用**授权码**而非登录密码，并开启 SMTP |
| 局域网访问被拒 | 未设访问密码或密码错误；服务需以 `--lan` 启动 |
| 云端/容器里 AI 报网络错误 | 容器无外网出口 → 改用内网模型或开放出网 |
| 想重置全部数据 | 停服务 → 删除 `data/data.db*` → 重启（会重新引导） |

日志位置：`{数据目录}/logs/mindmate.log.<日期>`；提高日志级别：`MINDMATE_LOG=debug`。
