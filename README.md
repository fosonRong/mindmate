# 智伴 Mindmate

> 一个懂你的 AI 工作生活伴侣 —— 记录、待办、提醒、AI 整理、习惯养成一体。
> 单一二进制同时服务**桌面端（C/S）**与**浏览器端（B/S）**，数据全部保存在本机。

| | |
| --- | --- |
| 技术栈 | Tauri 2（Rust）+ axum + SQLite + Vue 3 + TypeScript |
| 安装包体积 | **3.33 MB**（Windows NSIS，目标 ≤10MB） |
| 运行内存 | 约 60–120MB（复用系统 WebView，不打包 Chromium） |
| AI 支持 | DeepSeek / 智谱 GLM（默认双预设，GLM-4-Flash 免费）+ OpenAI / 通义 / Kimi / 本地 Ollama；**双协议自动识别**（OpenAI 兼容 `/chat/completions` 与 Anthropic 兼容 `/v1/messages`），Base URL 可自由填写且不会被重置 |
| 数据存储 | 本机 SQLite（WAL），除主动生成 AI 内容外零联网 |

## 一、快速开始

### 1. Windows 桌面端（主力形态）

```bash
# 构建安装包
npm install --prefix apps/web
npm run web:build
cd src-tauri && ../apps/web/node_modules/.bin/tauri build --bundles nsis

# 产物
#   src-tauri/target/release/bundle/nsis/Mindmate_1.0.0_x64-setup.exe   (3.33 MB)
#   src-tauri/target/release/mindmate.exe                               (8.80 MB，绿色版可直接运行)
```

安装后：托盘常驻，`Alt+Z` 全局速记，点击通知可直达录入。

### 2. 浏览器端（B/S，同一后端）

桌面端启动后，浏览器访问 `http://127.0.0.1:17801` 即是同一套界面与数据。

### 3. 服务器模式（异地/多设备）

```bash
docker compose up -d
# 浏览器访问 http://<服务器IP>:17801 （首次打开设置访问密码）
```

> 完整部署指南（三种形态、HTTPS 反代、systemd、升级、备份、故障排查）见 [docs/部署文档.md](docs/部署文档.md)
>
> 迭代与商业化（**第一期：免费全功能 + 中英日韩四语 + 免登录 + 零成本发布/自动更新**；第二期：手机号/微信扫码登录、订阅 ¥9.9/月·¥98/年·¥198 终身、一机一码）见 [docs/商业化方案.md](docs/商业化方案.md)

### 4. 开发模式

```bash
# 终端 1：Rust 核心（含 API）
cd src-tauri && cargo run

# 终端 2：前端热更新（代理 /api 到 17801）
npm --prefix apps/web run dev
```

## 二、功能清单（对照需求文档 v3.0）

### FR-1 快速记录 ✅
- **自由录入，一次提交 = 一个节点**：无预置模板、无必填项，自动记录录入时刻
- 今日页时间线展示当天全部节点（时刻 + 内容 + 标签），支持行内编辑/删除
- **桌面全局热键 `Alt+Z`** 唤出速记浮窗，回车即存、0.5s 绿勾反馈后自动关闭
- 浏览器端页面顶部常驻速记框（移动端同样可用）
- 补录历史日期并标记「补录」角标
- 每日目标（默认 4 条/天）可修改或关闭，超额显示「超额 n 条」
- 内容标签（工作/生活/健康/学习）
- **多端实时同步**：SSE 推送，桌面录入后浏览器 1 秒内可见

### FR-2 周期视图与进度 ✅
- 今日/周/月三视图，每视图顶部**双进度条**（记录进度 + 待办完成率）
- 周视图：周一~周日 7 列按日聚合，每日显示节点数、待办完成率环、内容摘要
- 月视图：月历网格按日聚合（节点数徽标 + 摘要），点击进日详情抽屉（可补录）
- 连续记录天数（🔥 streak）展示于今日/周视图与状态栏
- 进度条分级配色（<30% 灰 / 30–70% 黄 / >70% 绿）

### FR-3 待办管理 ✅
- **四类自动归类**：今日 / 本周 / 本月 / 日程（含具体时间或跨月 → 日程），可手动改
- 字段：标题、描述、截止日期、截止时间、提醒时间、优先级（高/中/低）、标签、状态
- 状态流转：待处理 → 进行中 → 已完成；过期未完成自动标记「已逾期」并通知一次
- 筛选（分类/状态/优先级/标签）+ 关键词搜索
- 拖拽改期（列表拖到日历某天）+ 逾期项高亮
- **待办同时展示标题与详细说明**（说明折行最多两行，悬停可看全文）
- **日历格内直接显示待办标题**：月视图与待办中心日历都显示「标题 / 时刻+标题」，超出以 +n 归纳
- **月份筛选**：月视图与待办中心均支持 ◀ / ▶ / 月份选择器 / 「本月」快捷返回
- 智能排期建议（AI 可用时给自然语言建议，无 Key 时降级为规则建议）

### FR-4 提醒系统（上下文智能）✅
- 记录提醒频率：每小时 / 每 2 小时 / 每 4 小时 / 自定义分钟
- 生效时段（默认 09:00–21:00），时段外静默
- **上下文规则（本地实现，无需 AI）**：
  - 当日记录已达标 → **静默不打扰**
  - 存在逾期待办 → 提醒文案附带逾期标题
  - 连续多日未记录 → 温和关怀文案
- 待办到期提醒（单条可设提前 0/5/15/30/60 分钟）
- 勿扰时段（一次性指定日期 + 每天重复）
- 睡眠/休眠唤醒补偿：错过的提醒聚合为一条补发
- 托盘常驻（关闭窗口 = 隐藏到托盘，提醒继续生效）；服务器模式由服务端定时器驱动
- 桌面系统通知 + 浏览器通知 + 页面内横幅兜底
- **远程推送渠道（邮件 / Telegram / 企业微信 Webhook）**：应用未打开或服务器模式下同样收到提醒；凭据存系统安全存储；设置页可一键测试投递

### FR-5 AI 能力 ✅
- **双预设一键配置**：智谱 GLM（`glm-4-flash` 免费）/ DeepSeek（`deepseek-chat`），选中即自动填 Base URL 与模型名，只需粘 API Key
- 其余预设：OpenAI / 通义千问 / Kimi / 本地 Ollama（完全离线）
- **双协议自动识别**：Base URL 含 `/anthropic` 时自动改用 Anthropic 协议（`/v1/messages`），也可在设置页手动指定；两种协议均已用真实 Key 实测通过
  - 智谱 GLM：`https://open.bigmodel.cn/api/paas/v4`（OpenAI 兼容）或 `https://open.bigmodel.cn/api/anthropic`（Anthropic 兼容）
  - DeepSeek：`https://api.deepseek.com`（OpenAI 兼容）或 `https://api.deepseek.com/anthropic`（Anthropic 兼容）
- **Base URL 完全自定义**：保存后切换模型/提供商都不会恢复默认，另提供「恢复默认地址」「使用 Anthropic 兼容地址」两个快捷按钮
- 「测试连接」返回延迟与模型回显；API Key 存系统安全存储（Windows Credential Manager / macOS Keychain），界面不回读
- **生成能力**（全部 SSE 流式打字机输出）：
  - 晨间简报（昨日遗留 + 今日安排 + Top3 建议优先级）
  - 日报 / 周报 / 月报（含**已完成待办**与**当前进度**）
  - 晚安总结（完成/未完成/明日建议）
  - 周度智能复盘（完成率、节奏、拖延洞察、下周建议）
  - 智伴问答（本地检索组装上下文 → LLM 回答，可溯源到日期与记录）
- **无 Key 降级**：自动切换为本地模板拼装，功能不空转，界面提示可配置 AI
- Prompt 模板可自定义（7 类，支持 `{{date}} {{nodes}} {{todos}} {{progress}} {{days}} {{context}}` 变量）
- 发送前自动脱敏（手机号/身份证/邮箱/链接 → `[隐私]`）
- 报告归档与历史版本、一键复制 Markdown / 导出 .md

### FR-6 习惯与激励 ✅
- 连续记录天数（streak）+ **10 枚成就徽章**（起步/第一件事/三日-一周-三十日之约/手速达人/超额完成/汇报达人/复盘专家/记录满月），成就抽屉展示全部徽章与解锁条件
- **首次启动引导**：三步向导（使用方式 → 每日目标 → AI 模型可跳过），完成后不再打扰
- **月度小结卡**：本月记录 X 天 / 完成待办 Y 件 / 连续最长 Z 天 / 节点数与日均，月底高亮
- 克制原则：所有提醒与激励可关闭，无营销、无排行榜

### FR-7 设置与数据 ✅
- 提醒设置、每日目标、主题**三态**（跟随系统/浅色/深色，实时联动系统）
- 部署模式（本地 / 局域网 / 服务器）、访问密码（Argon2id + JWT）
- 数据备份导出（JSON，含全部记录/待办/设置/报告）与导入恢复
- **Markdown 归档导出（ZIP，按周期分文件）**：`daily/` 每日 · `weekly/` 每周 · `monthly/` 每月 · `todos.md` 待办总表 · `reports/` 报告
- 开机自启开关（桌面端，登录后自动启动保证提醒不中断）
- 深色主题完整令牌适配（语义色跨主题稳定）

### 架构能力 ✅
- **B/S + C/S 双架构**：一套 Rust 后端 + 一份前端产物，桌面与浏览器访问同一 URL、同一数据
- 三种部署模式：本地（默认，仅 127.0.0.1）/ 局域网（访问密码）/ 服务器（Docker 无头）
- 端口冲突自动顺延（17801 → 17820）
- 未认证访问拦截、密码错误锁定、SSE 令牌校验

## 四、项目结构

> Monorepo 采用 **npm workspaces**（根 `package.json` 声明 `apps/web`；本机未安装 pnpm，等价落地技术设计中的 pnpm workspace 方案，命令统一为 `npm run …`）。

```
smartLife/
├── core/                    # Rust 核心库（与桌面壳同进程）
│   ├── src/
│   │   ├── db/              # SQLite 数据层：迁移、CRUD、统计
│   │   ├── api/             # axum：REST + SSE + 静态托管 + 认证
│   │   ├── ai/              # OpenAI 兼容客户端、预设、模板、降级、脱敏
│   │   ├── reminder/        # 提醒调度器 + 上下文智能规则
│   │   ├── config.rs        # 运行模式与配置
│   │   ├── secrets.rs       # 系统安全存储 / token / Argon2
│   │   └── events.rs        # 事件总线（广播 → SSE + 系统通知）
│   └── tests/core_logic.rs  # 36 项单元测试
├── src-tauri/               # Tauri 2 桌面壳
│   ├── src/main.rs          # 窗口/托盘/全局热键/通知/命令
│   ├── src/assets.rs        # 前端产物内嵌（rust-embed）
│   ├── tauri.conf.json      # 打包配置（NSIS）
│   └── capabilities/        # 权限声明
├── apps/web/                # Vue 3 前端（桌面与浏览器共用）
│   └── src/
│       ├── api/             # 类型定义 + 客户端 + SSE 订阅
│       ├── stores/          # Pinia：app / nodes / todos
│       ├── views/           # 今日 / 周 / 月 / 待办 / 智伴 / 设置 / 速记 / 登录
│       ├── components/      # 时间线 / 待办项 / 日历 / Markdown / 进度条
│       └── styles/          # 设计系统（设计令牌与组件样式）
├── scripts/                 # 验收测试套件 + i18n 抽取工具（默认 290 项断言）
├── docs/                    # 需求文档 / 技术设计 / UI 设计 / 商业化方案 / 部署 / 验收报告
├── Dockerfile               # 服务器模式镜像
└── docker-compose.yml       # 一键部署
```

## 五、数据与隐私

- 所有数据存于本机 SQLite：
  - Windows：`%APPDATA%\Mindmate\data.db`
  - macOS：`~/Library/Application Support/Mindmate/data.db`
  - 服务器：`--data-dir` 指定（默认容器内 `/data`）
- 日志：`{数据目录}/logs/mindmate.log`（按天滚动）
- AI 调用仅在你主动点击生成时发生，且只发送所选周期的文本；发送前自动脱敏
- API Key 存系统安全存储，任何界面与接口都不回传明文
- 局域网/服务器模式：Argon2id 密码哈希 + JWT（30 天），未认证请求一律拒绝
