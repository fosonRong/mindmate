设计说明与 PRD 对照
1. 主题三态：右下角浮标可实时切换浅色 / 深色 / 跟随系统（跟随系统取浏览器当前配色偏好）。所有令牌在深色下按 UI 文档 2.1 映射生效。
2. 一次录入 = 一个节点：时间线每行即一次提交（含时刻与标签），无模板干预；补录节点空心圆点 + 「补录」角标（P1 第 4 条）。
3. 双进度条：今日/周/月三视图顶部均为"记录进度 + 待办完成率"并排（P1/P2/P3）。
4. 待办中心左右分栏：左侧分组列表（今日/本周/本月 + 筛选），右侧日历 + 选中日的【具体日程 / 待办事项】双栏（P4）。
5. 速记三入口：页面常驻速记框（P1）、全局热键浮窗（P7）、通知直达（P8）。
6. AI 报告：流式打字机 + 生成中工具条 + 降级信息条（P5）；报告含已完成待办与当前进度，日报结构符合 PRD FR-5.6。
7. 设置 AI 双预设：智谱 GLM / DeepSeek 大卡选择 + 测试连接 + 脱敏规则（P6），满足 FR-5.1。
8. 提醒克制：达标即静默（无打扰）、逾期才加压、关怀文案不带红色警示（P8 三态文案）。
9. 本稿为静态高保真：交互（拖拽、流式渲染、抽屉滑入）以标注形式指出，实现阶段按技术设计文档落地。
